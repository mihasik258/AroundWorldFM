# Изменения

## 2.1.0

### Добавлено
- Миграции Alembic вместо `create_all`; проверка согласованности моделей в тестах и CI.
- Вход и привязка Telegram (Mini App, deep-link через бота), Telegram-бот: `/now`, `/favorites`, `/link`.
- Экран аккаунта: способы входа, пароль, сессии, удаление аккаунта.
- `GET /stations/{id}`, `/health/ready`, `X-Request-ID`, JSON-логи, CLI (`seed`, `create-admin`, `check-streams`).
- Продакшен-стек: Caddy с автоматическим HTTPS, бэкапы PostgreSQL, лимиты ресурсов; CI на GitHub Actions, Dependabot.

### Изменено
- Каталог добирается командой `import-stations` из Radio Browser: по странам, только HTTPS-потоки, лимит по площади страны, станции без координат — у столицы. В локальной базе после импорта: 2801 станция в 198 странах против 1930 в 134; Африка 172 → 316, Южная Америка 127 → 376, Океания 21 → 70.
- Глобус получает компактную карту станций (`/stations/vibe/map`): в 38 раз меньше данных; карточка станции загружается при выборе.
- Проверка потоков идёт порциями по сроку, а не всем каталогом раз в час.
- Инерция и доводка глобуса считаются по времени, а не по кадрам: одинаково на 60- и 144-герцовых экранах и на слабых устройствах.
- Интеграция с аккаунтами Spotify удалена (миграция `0002`): Spotify не выдаёт доступ к Web API для неограниченного числа пользователей частным проектам. Ссылка «Найти в Spotify» осталась.
- Глобус: свободное вращение, после остановки включается ближайшая станция.
- Авиарежим, окно языков и админ-панель оформлены в стиле радио; названия языков на русском.
- Языки станций приведены к единому виду (94 варианта написания → 64 языка), станции с условными координатами перенесены в столицы своих стран (миграция `0003`).
- Шрифты подключаются со своего сервера вместо Google Fonts; превью ссылки для Telegram и соцсетей, иконки для домашнего экрана.
- Контраст второстепенного текста поднят до WCAG AA, масштабирование страницы на телефоне снова разрешено.
- В «Что играет» не показываются служебные метки вроде рекламных вставок.
- Прицел в центре глобуса показывается только во время вращения и сжимается на выбранной станции; станции на ночной стороне светятся тёплыми огнями, на дневной приглушены, переход плавный через сумерки.
- Проверка потоков запускается в фоне по расписанию под advisory-lock.
- Демо-пользователи создаются только при `SEED_DEMO_USERS=true`.

### Исправлено
- Уязвимость: сессии полётов изменялись без авторизации (эндпоинты удалены).
- SSRF через URL потоков, `javascript:`-ссылки в станциях, гонка в избранном, утечка введённых значений в ошибках валидации, утечка деталей ошибки БД в health.
- PyJWT обновлён до 2.15.1 (14 уязвимостей).
